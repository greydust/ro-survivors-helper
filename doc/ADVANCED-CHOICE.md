# 進階自動選卡

主城右下角「自動選卡」開啟設定。預設關閉；多個設定檔、目前選用檔案及每個檔案的啟用、技能規則、道具規則、詳細順序保存於瀏覽器 `greydust.ro.advanced-choice.profiles.v1`。舊 `greydust.ro.advanced-choice.v1` 自動遷移成「預設」，並保留目前設定的相容性寫入。啟用時取代舊右鍵／長按自選，關閉後舊功能仍可使用。設定不隨每場重設。

## 技能

主城浮動「自動選卡」按鈕長按 0.3 秒後可拖曳（手機觸控與滑鼠皆可），拖曳放開不會開啟設定。位置在本頁保留並限制於可見畫面內。開啟遊戲內視窗時，按鈕與已開啟的選卡設定暫時隱藏，全部關閉後恢復。

- 新技能：必拿／填充／必不拿；未設定預設填充。
- 升級：選取／無視／放逐；未設定預設選取。「優先」即選取，不增加第四種狀態。
- 先放逐出現的放逐升級卡，再取最左必拿新技能。
- 沒有必拿新技能時，只在拿完填充後仍留得下所有未取得的必拿技能時，取最左填充。保留格數只計入目前角色原生 `freshChoices()` 真正可取得的技能，不計其他職業、武器／盾牌不符或已放逐的技能。
- 技能未滿且剩餘格不足以再拿填充時，使用原生整副刷新；每次刷新後從第一步重新判斷，仍無符合時繼續刷新，直到選到符合的卡或原生刷新次數耗盡，再繼續後續升級卡判斷。
- 然後依詳細清單選「選取」升級；同條目符合多張取最左。未列入清單但設定選取的升級排在詳細清單之後，再取最左無視升級。
- 詳細清單可新增、刪除、上下移動；每條目選一技能與零到多個升級種類。零個代表任意；多個採任一符合，複合升級包含任一指定部分即符合。
- 原生只剩肉類補血卡時可以選取；必不拿新技能、放逐升級不作最後亂選的備案。

技能清單、詳細優先序與專屬神格列出目前職業及繼承職業的完整技能池，包含所有天賦分支能解鎖的技能，不要求已分配天賦，也不依目前武器／盾牌隱藏。普攻提供各種武器版本；法師及其進階職業同時提供遠程與近戰屬性附魔，可在點天賦前預先設定。實際自選只處理遊戲原生提供的卡片，必拿保留格仍依原生 freshChoices() 計算，尚不可取得的技能不占保留格。其他職業的舊設定隱藏但保留，移動順序只交換目前可見條目。

目前角色優先透過原生主城「角色」顯示回呼讀取，暫時觀察其角色查找並立即還原，再透過原生返回回呼關閉角色頁，因此也支援只存在遊戲記憶體中的線上存檔。後備僅唯讀角色 roster 與同命名空間的裝備資料，以主城自身名牌作唯一比對；讀取不到或存在同名歧義時不顯示其他職業作為替代。每次開啟設定重新讀取角色與裝備。

技能清單包含主動、被動與可升級的普攻。升級種類從原生技能的 `upgradeAspects()` 和 `effects` 讀取，包含各技能自己的特殊效果。只在主城設定需要時建立獨立技能實例讀取 metadata；不呼叫 `rollUpgrade()`、不操作戰鬥中的實例。被動沒有細分升級種類時使用任意升級。

## 五種道具

藥水、秘藥、祝福、料理、神格各有多選目標；全部不勾代表該種類任意。每種類另設升級的選取／無視／放逐。

1. 先放逐設定放逐、且目前確實持有同一道具的升級卡。
2. 出現指定的新道具時，選稀有度最高；同稀有度選最左。
3. 否則選最左設定任意的新道具。
4. 否則只對已設定目標、但目前尚未持有任一目標的種類，使用原生單卡刷新；持續到取得目標或原生次數耗盡。畫面沒有那個種類的卡時，不能對不存在的卡刷新。
5. 再取稀有度最高的選取升級，同稀有度選最左。
6. 再取稀有度最高的無視升級，同稀有度選最左；不會越過選取規則。
7. 仍沒有符合時，取稀有度最高的升級（包含放逐資源耗盡後留下的升級）。
8. 如果可選的全部都是新道具，使用原生「重抽整組」，重回第一步；只要有次數就可繼續。
9. 整組重抽不可用時，選稀有度最高的新道具。同稀有度均取最左。

神格的多選清單除了 13 種通用神格，另包含目前角色技能池中原生允許作為神格的主動技能（技能 ID 即神格道具 ID；不包含普攻與被動）。實際戰鬥仍由遊戲原生規則決定哪些已取得技能的神格能出現。切換職業後，其他職業的專屬神格設定不參與目前場次的目標刷新。

## 背景選取與取得訊息

`onLevelUp`／`onChest` 在啟用進階自選時只記錄原始 offers，排程背景判斷，不建立原生 picker，因此沒有卡片進場、翻轉與離場動畫。完成時直接呼叫原生 `choose`／`chooseChest`；連續升級以短排程接續，不增加遞迴深度。

刷新、放逐仍使用原生方法與次數，offer 替換／刪除方式比照原生 QT／ZT。道具替換直接交給原生完成方法，代表依設定自動接受替換。技能結果使用原生 `events.onLoot` 顯示取得／升級訊息；道具的原生 `chooseChest` 已會發出同一事件，不額外重複通知。

沒有安全可選的技能、方法失敗或按 Escape 時，才以當前更新後的 offers 呼叫原生 picker，保留手動控制與原生組隊倒數。死亡、換場、關閉設定會停止舊排程。背景完成仍走原生遊戲方法，不自行改寫技能等級、道具、存檔、冷卻或組隊同步。保留原生 UI 驅動作為已顯示 picker 的相容流程。

## 多設定檔

支援切換、新增（複製目前）、重新命名、移除；至少保留一個，最多 100 個。各設定檔的規則與詳細順序互相獨立；切換設定檔會中止尚未完成的背景選擇，避免混用兩份規則。

可以下載目前設定檔或全部設定檔的 JSON，也可以貼上 JSON 或選擇檔案匯入。匯入採新增，不覆蓋現有檔案，同名自動加序號；所有內容驗證通過才一次加入，任一筆無效則保留全部原設定。格式為 `{format:"ro-survivors-advanced-choice",version:1,profiles:[{name,settings}]}`，單檔最多 1 MB；技能／道具規則、順序、ID 及長度皆檢查，拒絕原型污染名稱。

## 2.2.9 完整職業技能設定

清單以原生職業繼承與天賦 metadata 建立，全部天賦分支的 learn 技能皆可預先設定，包含尚未點出的技能。尚未裝備盾牌／指定武器的技能仍可設定。普通攻擊提供所有武器版本；法師及繼承法師的職業另提供 atk_infused 與 atk_infused_melee。天賦重置或換武器不會移除這些設定項目，既有設定繼續使用。普攻不列為專屬神格。

測試涵蓋 16 個三轉職業的所有天賦分支、兩種職業資料表示法、繼承技能、設定 UI、升級優先序、未裝盾牌及附魔普攻背景選卡；另沿用原生 offers 與未取得必拿技能保留格的回歸測試。沒有操作實際帳號。
