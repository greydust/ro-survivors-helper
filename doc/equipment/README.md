# 各部位裝備：獨立網頁

直接以瀏覽器開啟 `index.html`，不需登入、啟動遊戲或安裝使用者腳本。文字、分類與搜尋可離線使用；原遊戲裝備圖片需要網路。

與助手過濾器共用 `equipmentGroups`、`equipmentTiers`、`actualEquipmentBonuses`、部位與武器類型資料。目前共 488 個裝備 ID、10 個部位分類，提供單手／雙手武器細分類、跨部位搜尋、39 個職業與 T1～T8 篩選、所選 Tier 的屬性、理論最高 GS、詞綴分配及中文掉落來源。同名不同 ID 分開呈現，避免把其中一件的詞條誤套到另一件。

固定加成來自實際遊戲定義與 Tier 詞條，不再使用舊圖書館的說明。固定加成區未含精煉、品質基礎面板或隨機詞綴；來源清單直接列出關卡與怪物，不標示 Tier，並依關卡去重合併；隨機登場的特殊頭目標示「闖入者」。Tier 仍顯示於固定屬性區與助手的保留開關。沒有固定詞條的 Tier 明確顯示「無固定加成」。例如紫蝶髮帶 2208 沒有固定減傷，而同名 2209 的原生固定詞條不同，兩者分開顯示。

## 更新資料

1. 從遊戲首頁確認最新公開 `soul_linker` 與 `main` 模組網址，以及 `assets/manifest.json`，下載至本機暫存檔。
2. 執行 `npm run build`。
3. 執行 `node scripts/export-equipment-data.mjs <core暫存檔> <core網址> <main暫存檔> <main網址> <manifest暫存檔>`，以隔離 VM 初始化共用資料，禁止網路與計時工作；main 只擷取關卡資料與多周目設定，不執行主遊戲、登入或帳號流程。匯出會重建一般、聖誕節、元宵節與稀有首領掉落表、保留仍有效的關卡獎勵，並檢查助手的六周目／T8 上限是否符合原生設定。
4. 執行 `npm run build:equipment` 產生完整單檔 `index.html`。
5. 執行 `npm test`，確認資料、分類、搜尋及助手測試。

`data.json` 保留兩個模組的來源網址、SHA256、原生周目設定與日期；`template.html`、`page.js` 是網頁原始碼。發布的 `index.html` 已內嵌資料與介面程式，不需要讀取本機 JSON，也不會在瀏覽時匯入或執行遊戲程式。

## 職業、Tier 與理論最高 GS

搜尋右側可選 39 個職業及 T1～T8，預設劍士／T8／全部部位。職業篩選使用目前公開 main 的原生裝備條件，包含職業繼承與盜賊持弓例外；性別限制裝備只要任一性別可用便列出。Tier 限制依各件實際出產階級，第二章專有裝備不會列在 T1～T5。搜尋維持跨部位，但遵守目前職業與 Tier；結果依最高 GS 降序、同分依裝備 ID 排序。

每張卡只顯示選定 Tier 的基礎 ATK／MATK／DEF、固定屬性、理論最高 GS 與一組最高 GS 詞綴範例。一般掉落裝備固定為傳說品質、未精煉、★0、未插卡；僅有劇情獎勵來源的裝備採原生固定 Tier／品質例外。原生 legendary 詞綴為兩個不重複主屬性、第三類、第四類，以及該物品／職業／Tier 能骰出的技能傷害詞綴（若有，取原生上限 20%）。同分可能有其他配置；此分配只最大化 GS，不代表最高傷害或最佳配裝。

`export-equipment-data.mjs` 呼叫 `equipment-max-gs.mjs`，從公開主程式擷取原生 GS 權重、基礎裝備算法、職業條件及完整單件計分函式，在隔離 VM 計算；從原生 core 讀取詞綴範圍、可用第三類與 HZAF.pool。不是把已取整 GS 乘倍率，會沿用雙手武器／弓的原生 1.75 倍與取整順序。原生 GS 在最後取整前是加總，故可分別選最好的兩個不重複主屬性與各類詞綴，再用完整原生函式計分。

更新資料時可在既有匯出命令最後加 `--verify`，對八個指定案例完整枚舉所有合法詞綴組合並用原生計分器逐筆比較，更新 `tests/fixtures/equipment-max-gs-native.json`。本次共 12,780 組，包含一／八階、近戰／魔法、雙手武器、跆拳武器與防具等不同計分情況。`npm test` 驗證此原生參考值、全部輸出的分數與分配、原生職業限制、選定 Tier 顯示、排序、來源與搜尋。遊戲變更 minified 函式或詞綴格式時匯出器需重新核對；網頁保留資料來源及 SHA-256。

## 2.2.12 劇情獎勵 Tier／品質

普隆德拉巡邏徽章（22847）僅由普隆德拉城劇情獎勵提供，原生 iM 用 xf(stage) 決定 Tier，quality 使用稀有常數 Ol（2）；不是按擊殺掉落的 RO_LAPTIER。當前為固定 T2／稀有，無正常 T8 來源。助手的 equipmentTiers 對純獎勵來源只保留原始 Tier；匯出器直接讀取當前 script.reward 建立來源，不再沿用舊快照獎勵。混合一般掉落來源的物品仍照一般規則。

最高 GS 對純劇情獎勵使用原生稀有品質、Fv[2] 的主屬性＋第三類詞綴，不加傳說才有的第二主屬性／第四類／技能傷害；卡片標出固定品質，T8 篩選不顯示徽章。新增純獎勵 Tier 與 UI 回歸測試，並將徽章的 18 種合法詞綴組合加入完整原生枚舉；九例共 12,798 組。依據 main-BNOcv2PN.hzf64b3f03.js 與 soul_linker-DllBVIRO.hza78cd192.js。
