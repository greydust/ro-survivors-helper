# 職業天賦與技能

直接開啟 `index.html`。資料與程式內嵌，查詢不需要遊戲帳號；圖示由遊戲公開資產載入，需要網路。

- 上方選擇 39 個職業，下方切換「天賦／技能」。
- 天賦依原生職業繼承鏈顯示 1～3 個區塊，每區保留三個分支、節點位置、前置連線與技能解鎖標示。點選節點查看各級效果、前置滿級需求、分支點數需求與互斥路線。
- 影狼、叛亂者為三轉，但原生直接繼承忍者、神槍手，因此顯示兩個職業區塊。
- 技能包含繼承技能、各專精解鎖技能、可用武器的普通攻擊，以及魔法師的屬性附魔攻擊；各專精技能不代表可同時取得。
- 技能卡片列出初始、未強化的原生基礎數據：實際採用的基礎 CD、詠唱、技能內建傷害倍率、基礎傷害、數量、連擊、持續時間、觸發間隔與效果初始值。基礎傷害尚未計角色縮放、技能內建傷害倍率及敵人防禦，不是最終扣血值。距離採遊戲單位；各項不附逐欄小字說明。
- 「選敵方式」「選敵距離」「作用範圍」各自列出；增益技能的敵人接近檢查列為特殊施放條件，不當成選敵距離。一般近戰沿用原生 `Lv` 的固定 +30 距離，火箭術類明示可補選視野內敵人；標記優先、召喚物選敵與密集敵群等特殊技能另列規則。
- 選敵規則核對來源為本頁快照對應的公開模組與主程式。衝鋒攻擊說明寫「6 公尺」，但目前原生 `Jw=380`，選敵距離採實際常數 380，而非換算說明文字；原生技能效果敘述仍原樣保留。
- 加農矛等通用投射物技能未填 cfg.range 時沿用原生 600 遊戲單位；沒有可選目標時不發射。選敵距離與投射物速度／存活時間限制分開顯示，不能將未填個別 range 解釋為不需要敵人。
- 特殊施放技能未必有通用傷害欄位，保留可展開的原始施放定義，不將缺值當成 0；函式中的內部符號需對照來源模組。原生 `cdBase` 優先於設定的 CD，兩者都保留供查核。
- 強化上限取自原生升級面向及效果定義；百分比為翻牌累積加成，效果專屬上限則明示總值。傷害、急速等無固定上限的項目明確標示。舊 `maxLevel` 不是目前翻牌強化次數上限，不以它限制顯示。
- 火箭術、冰箭術、雷擊術與靈魂攻擊的數量強化會先截斷單次增量，再乘以 2：達到 +10 後停止出現，但末次強化可到 +12。頁面列出可達最高值，並說明停止門檻；已逐一用原生 `rollPart` 枚舉所有稀有度的可達累積值確認。
- 此頁只查詢，不配點、不修改遊戲或存檔。

## 更新資料

先從遊戲首頁確認目前 main、soul_linker 與 manifest 的公開網址，下載至本機，再執行：

```powershell
node scripts/export-job-data.mjs <共用模組檔> <共用模組URL> <主程式檔> <主程式URL> <manifest檔>
npm run build:jobs
node tests/job-page.test.cjs
```

匯出器以隔離 VM 執行共用資料模組，封鎖 fetch、不啟動 main、不登入遊戲。`data.json` 記錄來源、日期與 SHA-256。內部匯出名及強化規則若改動，需要重新核對；未知結構應停止匯出，不能猜測。
