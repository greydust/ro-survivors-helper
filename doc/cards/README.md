# 各部位卡片：獨立網頁

直接開啟 `index.html`，不需登入、安裝助手或連網。沿用裝備總覽的深色介面，提供插卡部位分類、名稱／能力／關卡搜尋、職業評分與排序版本選擇。所有篩選結果依選定版本的 GS 由高至低排序，同分以基礎卡片 ID 排序。

目前快照含 133 種卡片、七個原生插卡部位、39 個職業、798 筆版本資料。每張卡由最高版本列至普通版，包含每版 GS、能力及基礎關卡掉落來源。頭部沿用遊戲的 `headgear` 合併分類。

怪物類型可選「全部／小怪／Boss（含首領與 MVP）」，可與部位、搜尋及 GS 排序同時使用，切換時保留其他條件。

遊戲目前只有普通版、改、改2、改3、改4、改5，共六周目。僅列出遊戲內實際存在的版本，不外推倍率。GS 直接執行公開 main 模組的原生權重與 bonus 計分片段，再對完整卡片加成合計四捨五入；不把普通版已取整 GS 乘周目倍率。俄塞里斯的復活能力沿用原生不縮放例外。部分能力目前沒有 GS 權重，可能得到 0 GS，並非沒有能力。

## 更新

從遊戲首頁確認最新 core、main 與 manifest URL，下載至本機暫存檔後執行：

```text
node scripts/export-card-data.mjs <core檔> <core網址> <main檔> <main網址> <manifest檔>
npm run build:cards
node tests/card-page.test.cjs
```

匯出器在禁止網路與計時工作的隔離 VM 初始化公開共用模組；main 僅擷取周目設定與 GS 計分片段，不執行主遊戲或帳號流程。原生各版本卡片、中文能力與職業定義直接來自 core，不自行重建。`data.json` 記錄模組來源、SHA256、日期與原生周目設定；版本缺漏或新部位會中止匯出。更新遊戲格式時，需同步調整匯出器與已知卡片數值驗證。

`template.html` 與 `page.js` 為原始碼，`npm run build:cards` 將資料與程式內嵌成可直接開啟的 `index.html`。遊戲更新不會自動更新此快照。
