# 背包、倉庫與換裝預覽

鐵匠強化介面的裝備清單與選中裝備，若有精煉、升星或插卡，GS 後會顯示原始分數，例如 `GS 184 (109)`。括號內保留裝備品質、Tier、原有詞綴，排除精煉、升星與卡片。未加工的裝備不加括號。

精煉細項分組獨立於原生分類列，避免原生點選裝備時的 `innerHTML` 重建移除觸控目標。全清單已載入時，切換細項只套用篩選；點裝備重畫後立即恢復細項，不等待背景掃描。相同裝備的 GS、名稱及圖示未變時重用基底分數，避免每次點選都額外觸發原生重畫。

原始 GS 透過原生同步清單重畫計算：僅在顯示期間回傳 `refine: 0`、`star: 0`、空卡槽的裝備複本，讀取原生 GS 後立即還原並重畫真實清單，不更動裝備或存檔。2026-11-17 核對公開 `main-BNOcv2PN.hz70eb4bc4.js` 的鐵匠 `Mq`、評分 `or`／`OC` 與升星倍率 `RO_STARM`；原生評分保留當前職業權重。`tests/auto-pick.test.cjs` 驗證三種加工、原始品質／Tier／詞綴保留、重畫、標註不重複與資料不變。

背包及卡普拉倉庫將原生武器／頭部分類細分為單手武、雙手武及頭部上／中／下。武器下方另有單行、可橫向捲動的武器類型。分類在原生排序及分頁之前套用；不以隱藏當頁格子的方式代替全清單分類。

換裝候選列補齊內建／Tier 詞條、兩個主要屬性、副屬性與技能傷害，按實際精煉倍率顯示。原生穿裝、轉卡確認、保護與新裝備標記流程仍由遊戲執行。

## 裝備比較 GS

兩邊 GS 與候選清單 GS 後，顯示括號基底分數，例如 `GS 184 (109)`。基底排除卡片、精煉加值與星數，保留品質、Tier、詞綴與目前職業權重；未加工裝備亦顯示基底分數，方便對照。

原本 GS、差值、升降箭頭與中間屬性比較全部沿用遊戲原生結果，不再模擬套用目前裝備的卡片。實際選取、穿裝與保存流程不變。

僅在原生同步顯示流程中觀察候選評分 `map`，辨識 `{g: 裝備, s: 分數}` 結果後，使用同一個原生評分回呼計算無卡片、`refine: 0`、`star: 0` 的複本。顯示後立即還原暫時觀察的陣列方法，不修改帳號、裝備或存檔。無法辨識評分流程時不添加猜測分數。

## 驗證

`tests/fixtures/inventory-native.json` 保存上述版本的原生比較、重畫及穿裝函式片段，供隔離測試執行。測試包括 GS／中間數值沿用原生、括號排除三種加工、空槽與部分插卡、容量不足／零插槽、雙手武器與盾牌、新裝備保存及重畫、例外還原、倉庫 60 件分頁前分類與原生批次範圍、精煉詞條及真實 MutationObserver 收斂。測試不等於完整遊戲或 iPhone Safari 實機驗證。

保留既有觸控安靜期：手指操作期間不由背景掃描新增分類、重畫比較或更新詞條。

## 升星／洗鍊的基底 GS

升星／洗鍊視窗（`#starforge`）的清單與詳細資料同樣顯示基底 GS。依 2026-11-17 公開 main 模組的 `RO_SF` 重畫順序，在 `#sf-mats` 寫入後、原生裝備 `map(row)` 執行時取得原生列 renderer；計算複本後，先還原 Array.map，再讓原生 renderer 繼續顯示實際裝備。初次開啟由原生開窗回呼包裝涵蓋；空清單或重畫例外由 microtask 清除暫時掛鉤。只讀取 renderer 輸出的 GS，不重點裝備、切換頁籤或呼叫升星／洗鍊請求，因此保留選取、詞綴、風險確認及結果訊息。

`tests/fixtures/starforge-native.json` 保存該版本原生 runtime；測試以此 runtime 驗證首次開啟、選取、升星／洗鍊切換、風險確認不被清除與重複更新收斂。

## 連續升星

升星頁籤的原生按鈕旁提供「連續升星至」與 ★1～★10 目標選單，預設 ★4。僅允許高於目前星數的目標。每次沿用原生升星按鈕及其「確定？再按一次」確認，等待本次回應後才送下一次；失敗掉星仍繼續嘗試。達標、材料／卡普拉點數不足、請求錯誤、30 秒回應逾時、切換裝備／頁籤、關閉視窗或手動操作原生升星按鈕時停止。洗鍊頁籤隱藏此功能，不自動洗鍊。

「停止」與 Escape 停止後續操作，不能撤回已送出的單次升星。停止後在原生請求完成前不可重啟。`tests/auto-star.test.cjs` 使用保存的原生升星 runtime 與模擬回應，驗證達標、失敗重試、原生風險確認、單一在途請求、停止、逾時、材料／費用不足、錯誤及介面切換；不對真實帳號升星。
