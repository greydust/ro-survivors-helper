# 不透過 Tampermonkey 執行

每次 `npm run build` 同時產生使用者腳本與 `dist/RO倖存者助手.console.js`。兩者共用相同功能，Console 檔移除使用者腳本的 metadata，適合直接貼入開發者工具。

1. 開啟 https://ro.hans-webgametw.com/ ，建議先停在主畫面、尚未進關。
2. 開啟瀏覽器開發者工具的 Console，確認目前選取遊戲頁面的執行環境。
3. 用文字編輯器開啟 `dist/RO倖存者助手.console.js`，複製全部內容、貼入 Console 後執行。
4. 可依原本方式右鍵或長按設定技能／道具自選。已進關才執行時，部分功能需等遊戲下一次 tick 或下一場才掛載；為確保完整啟動，建議進關前執行。

重新整理、關閉分頁或重新開啟遊戲後，必須再執行一次。可將內容保存為開發者工具的 Snippet，方便下次手動執行。此方法不會自動更新，更新時請換用重新建置的檔案。

同一頁重複貼上，或與本次更新後的 Tampermonkey 版同時載入，會保留第一個已啟動的實例；要改用新版本請先重新整理。從較舊且沒有重複保護的版本切換時，先停用舊腳本並重新整理。

「保持離線遊玩」只能攔截助手啟動後建立的主城 WebSocket；Console 注入前已存在的連線無法回頭追蹤或關閉。若需要開頁立即攔截，仍使用 Tampermonkey 的 document-start 載入方式。

手機瀏覽器通常沒有可直接操作的開發者工具 Console；這個方法主要供桌面瀏覽器使用，並不是手機安裝腳本管理器的直接替代品。
