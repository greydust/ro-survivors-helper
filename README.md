  - 總插槽不足時依原卡片順序計入能容納的卡片，並提示未計入數量
  - 候選裝備已有任何卡片時，使用它現有的卡片比較，不補空槽
  - 比較預覽不會實際插卡；換裝仍使用遊戲原本的轉卡確認

- 新增怪物潮範圍顯示
- 右下角固定顯示「怪物潮(X/Y)」：X 為本波累計成功出生數，Y 為理論總數，分批出生時即時更新，生成結束後轉為綠字（地形限制可能使 X 小於 Y）。完成三秒後重置為「怪物潮(-/-)」。窄版面板可用 ＋／－ 折疊怪物明細；手機版置於左上「角色詳細資料」按鈕下方、預設折疊，選擇卡片時隱藏面板，下方以 N / M 顯示場上總數／目前波次刷怪上限，並列出各種類目前的數量
- 左側 buff 欄下方新增「角色詳細資料」，即時查看生命、減傷、Flee、尋寶、爆擊與全部原始 stats 欄位
- 進關前各怪物圖示下方依序顯示名稱、高對比等級標籤與隨機生成時段，多個時段分行顯示；一般怪與頭目皆顯示等級，包含選取周目的經驗判定修正

- 手機介面：放大觸控按鈕、裝備卡片單欄排列、分類列左右滑動，細項過濾器與角色資料適應小螢幕。手機仍需可執行使用者腳本的瀏覽器與腳本管理器。

可不透過 Tampermonkey，直接將建置後的 `dist/RO倖存者助手.console.js` 貼入遊戲頁面的 Console 執行；使用步驟與限制見 [Console 使用說明](doc/CONSOLE.md)。

- Safari 專用本機診斷：自動保存錯誤與選卡事件，重新整理後可複製上次紀錄；網址加上 `?rodiag=1` 可直接開啟診斷面板，不會自動上傳。

- 戰鬥中掉落物選項
  - 解除磁鐵數量上限（預設關閉）
    - 解除地上同時最多三個磁鐵的限制；掉落機率不變，關閉後恢復原生限制。
  - 隱藏掉落物效能優化（固定啟用）
    - 掉落物隱藏時，略過浮動動畫、顯示位置及光柱更新；重新顯示時補回動畫時間。
    - 保留掉落物與原生拾取判定，不刪除經驗或道具；大量物件的距離判定仍有運算成本。
