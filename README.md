- 技能/道具按右鍵，或在手機長按約半秒，可設定自動選擇（移動、滑動與多指操作會取消長按）
- 關卡結束後吸取所有地上的裝備
- 鐵匠能選擇細部部位
- 商人裝備圖鑑過濾器：中文掉落來源、Tier 保留開關（含多周目 T4／T5，提供過濾 T1～T4 以下的批次按鈕）、稀有度排除、可命名及排序的共用細項過濾器、屬性多選與技能傷害最低值設定
- 自動精煉功能
- 選項 > 遊戲
- 新增保持離線遊玩
- 戰鬥選項
- 新增隱藏小地圖磁鐵
- 新增怪物潮範圍顯示
- 裝備掉落區下方顯示「怪物潮(X/Y)」：X 為本波累計成功出生數，Y 為理論總數，分批出生時即時更新，生成結束後轉為綠字（地形限制可能使 X 小於 Y）。完成三秒後重置為「怪物潮(-/-)」。窄版面板可用 ＋／－ 折疊怪物明細；手機版固定右下、預設折疊，選擇卡片時隱藏面板，下方以 N / M 顯示場上總數／目前波次刷怪上限，並列出各種類目前的數量
- 左側 buff 欄下方新增「角色詳細資料」，即時查看生命、減傷、Flee、尋寶、爆擊與全部原始 stats 欄位
- 進關前各怪物圖示下方依序顯示名稱、高對比等級標籤與隨機生成時段，多個時段分行顯示；一般怪與頭目皆顯示等級，包含選取周目的經驗判定修正

- 手機介面：放大觸控按鈕、裝備卡片單欄排列、分類列左右滑動，細項過濾器與角色資料適應小螢幕。手機仍需可執行使用者腳本的瀏覽器與腳本管理器。

可不透過 Tampermonkey，直接將建置後的 `dist/RO倖存者助手.console.js` 貼入遊戲頁面的 Console 執行；使用步驟與限制見 [Console 使用說明](doc/CONSOLE.md)。

- Safari 觸控：一般技能／道具列可長按設定；自選命中時直接選取、不開視窗；未命中與需確認替換時保留原生選卡流程，手機後備選卡保持可點。
