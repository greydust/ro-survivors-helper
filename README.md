# RO 倖存者助手

小地圖左下角的長條圖按鈕右側新增眼睛按鈕。點擊後依目前視野距離掃描可到達的站位，以綠色三角形標記估計怪物潮出生成功率最高的位置。計算會檢查地圖邊界、可走地形與連通性，分批掃描每個 32 單位格心，並對前 24 個候選點精算三次出生嘗試；百分比為地形抽樣估計。掃描完成後圖示會變成斜槓眼睛，再點一次關閉標記並恢復眼睛圖示，下一次點擊會重新掃描；掃描期間再次點擊無效。視野、地圖或開門狀態改變後，請重新點擊掃描。

「選項 → 遊戲」可開啟「自動進世界王」（預設關閉，保存於此瀏覽器）。遊戲顯示世界王入口時，助手會點擊原生「進場」一次；額滿沿用原生排隊，資格與進場結果由遊戲判定。需讓遊戲頁面保持開啟與連線，「保持離線遊玩」優先。為避免每秒重繪或重連造成連點，同一提示不重試，重新建立的提示也有 30 分鐘防重複保護；失敗請手動重試，關閉此選項不會取消已送出的進場或排隊。

新版相容性與 Safari 手機修正見 [2026-11-18 核對紀錄](doc/COMPATIBILITY.md)。

2.2.23 已依 2026-11-20 公開遊戲程式更新資料並核對相容性。新增職業網頁：選擇職業後切換天賦／技能，依轉職繼承列出完整天賦樹、各級效果，以及技能強化項目與上限。圖示需連線載入。

獨立查詢網頁：[裝備總覽](doc/equipment/index.html) · [卡片總覽](doc/cards/index.html) · [職業天賦與技能](doc/jobs/index.html)。卡片依部位分類，列出各版本能力，並可選擇職業、依 GS 由高至低排序；裝備可依職業與 Tier 篩選，顯示該階屬性及傳說滿詞綴、未精煉／升星／插卡的理論最高 GS 與詞綴範例；直接開啟 HTML 即可使用。

RO 倖存者助手提供裝備整理、換裝預覽、連續精煉／升星與戰鬥介面輔助，適用於 https://ro.hans-webgametw.com/ 。

### 背包、倉庫與換裝比較

- 背包與倉庫的武器細分為單手武／雙手武，頭部細分為上／中／下；武器下方提供可左右滑動的類型列。
- 換裝候選列補充內建與 Tier 屬性、主要屬性、副屬性及技能傷害。
- 裝備比較兩邊與候選清單的 GS 後加上括號基底分數，排除卡片、精煉加值與星數，保留品質、Tier 與詞綴。
- GS 差值、升降箭頭、屬性比較與換裝確認均沿用遊戲原生邏輯。

### 進階自動選卡

主城右下角「自動選卡」可設定初始技能、升級與五種道具的自動選擇。設定會保存，預設關閉；啟用時取代右鍵／長按的舊自選。支援必拿技能保留格、升級詳細順序、原生刷新／放逐及手動中止。背景完成自選並顯示原生取得訊息；支援多設定檔的命名、切換、匯入與匯出。使用規則與維護依據見 [進階自動選卡](doc/ADVANCED-CHOICE.md)。

### 鐵匠：精煉與升星

- 精煉清單提供單手武、雙手武、盾牌、頭部上、護甲、披肩、鞋子分類。
- 升星／洗鍊提供全部、單手武、雙手武、頭部上／中／下、護甲、盾牌、披肩、鞋子與飾品過濾；洗鍊限傳說裝備。
- **連續精煉至 +N**：選擇 +1～+10 目標，預設 +4，沿用原生精煉與風險確認。達標、爆裝、材料不足、回應異常或切換／關閉介面時停止。
- **連續升星至 ★N**：在升星頁籤選擇 ★1～★10 目標，預設 ★4。失敗掉星後仍會繼續嘗試；達標、材料或卡普拉點數不足、回應異常、切換裝備／頁籤或關閉介面時停止。洗鍊頁籤不提供連續操作。
- 連續操作每次等待原生回應才進行下一次，可按「停止」或 Escape 中止後續操作；已送出的單次操作仍會完成。
- 精煉與升星／洗鍊介面中，加工過的裝備顯示 `GS 現值 (基底值)`。基底 GS 排除精煉、升星與插卡，保留原有品質、Tier 與詞綴；清單及選中裝備皆顯示。

### 商人裝備過濾器

- 以裝備圖鑑整理條件，提供中文掉落來源、部位與武器類型分類、搜尋、Tier 保留開關及稀有度排除。
- 支援多周目 T4～T8；可選擇 T1～T7 以下，再按「套用過濾」批次設定。
- Tier 開關橫向排列，預設顯示最高階固定屬性；卡片直接列出關卡與掉落怪物，來源不標 Tier；展開「各階屬性」可查看完整能力，相同屬性合併顯示。
- 內建不可刪除的「預設」細項過濾器，並可新增、命名、排序及移除自訂過濾器。每件裝備可多選自訂過濾器，符合任一個即保留；未選時自動套用「預設」，預設不列於可選清單。
- 編輯後按「儲存並套用」生效，支援設定匯入／匯出。商人依條件勾選不需要的裝備，出售仍由玩家操作。

### 戰鬥偏好與效能量測

- 記住戰鬥 1x／2x 按鈕的選擇，下次單人遠征自動沿用；組隊、無限塔、PVP／公會戰與故事模式遵守原生速度限制。
- 「選項 → 畫面」提供敵人、隊友與自身三條特效透明度滑桿，範圍 0～100%，設定自動保存。0% 隱藏對應來源的特效與預警；技能、命中與傷害判定照常，角色本體、掉落物與傷害數字維持原樣。
- 「選項 → 遊戲 → 戰鬥效能量測」可記錄 15 秒拾取、怪物、技能、特效與繪圖 CPU 耗時，並複製報告；資料僅在本分頁量測。

### 角色狀態數值

- 「角色 → 狀態」的受到傷害、Flee 與爆擊率超過硬上限時，在有效數值後以括號顯示原始值，例如 `-60% (-90%)`、`50% (73%)`、`100% (123%)`。
- 速度、範圍與近戰距離沿用原生顯示；數值顯示不改變角色屬性或存檔。

### 選項

- **遊戲 → 保持離線遊玩**：不自動連入主城多人伺服器，保留帳號登入與存檔同步。
- **戰鬥 → 隱藏小地圖磁鐵**：隱藏小地圖上的磁鐵標記。
- **戰鬥 → 顯示怪物潮第一圈範圍**：在小地圖顯示第一圈距離與外緣參考範圍，預設開啟；地形仍可能限制實際出生位置。
- **戰鬥 → 解除磁鐵數量上限**：預設關閉。開啟後解除地上同時最多三個磁鐵的限制，掉落機率不變；關閉後恢復原生限制。
- **戰鬥 → 合併金錢**：預設關閉。單人戰鬥將超過 350 個、未吸取的金錢堆併入較近的保留堆，金錢總額不變；開啟時也整理既有堆積。組隊與確定性模式不套用。
- **戰鬥 → 隱藏戰鬥天氣**：停用戶外雨滴、閃電、天氣霧色與動畫更新，室內光影維持原樣。
- **戰鬥 → 顯示 FPS**：在戰鬥畫面左下角顯示更新率，每半秒更新；暫停與選卡時隱藏。
- 掉落物隱藏時，自動略過浮動動畫、顯示位置及光柱更新；恢復顯示時補回動畫時間。掉落物與原生拾取判定仍保留。

### 遠征與戰鬥資訊

- 進關前直接讀取遊戲內部資料，顯示怪物名稱、一般怪與頭目的等級，以及一般怪的隨機生成時段；周目設定自動讀取目前頁面使用的主程式，讀取失敗時多周目等級顯示「—」。等級包含選取周目的修正，多個生成時段分行顯示。
- **技能／道具自選**：電腦按右鍵、手機長按約半秒設定，名單每關重設；移動、滑動或多指操作會取消長按。符合多個選項時優先選最高稀有度，同品質選最左。
- 自選成功時直接選取；未命中或需要替換確認時保留手動流程。
- 勝利後觸發一次全圖磁鐵拾取，單人／房主及隊員沿用各自原生拾取流程。
- **怪物潮統計**：顯示本波累計成功出生數／理論總數，分批生成時即時更新；完成後轉為綠字，三秒後重置。地形限制可能使成功出生數較少。
- **場上怪物統計**：顯示目前數量／目前波次上限，可用「＋／−」展開各種類數量。電腦置於右下；窄版置於左上原生 DPS 下方、預設折疊，選卡時隱藏。長按標題列約 0.3 秒後可拖動。
- **角色詳細資料**：電腦版按鈕位於右下怪物統計上方，手機版位於怪物統計下方；長按約 0.3 秒後可獨立拖動，位置於本頁保留。點擊查看生命、減傷、Flee、尋寶率、爆擊率、爆擊傷害與原始 stats。尋寶率為內部數值，不是單件物品掉落機率。

### 手機與 Safari

- 放大觸控按鈕，裝備卡片單欄排列，分類列可左右滑動；細項過濾器與角色資料適應小螢幕。
- 觸控期間暫緩助手背景介面刷新，保留原生點選操作。手機仍需可執行使用者腳本的瀏覽器與腳本管理器。
- Safari 提供本機診斷，記錄錯誤、觸控事件及助手介面狀態，不會自動上傳；重新整理後可查看並複製上次紀錄。網址加上 `?rodiag=1` 可直接開啟面板。

更新腳本後請重新整理遊戲頁面，讓新版本生效。

也可將建置後的 `dist/RO倖存者助手.console.js` 貼入遊戲頁面的 Console 執行；使用步驟與限制見 [Console 使用說明](doc/CONSOLE.md)。建置與發佈流程見 [工作流程](doc/WORKFLOWS.md)。

### Safari 鍛造相容性（2.2.5）

Safari 的精煉／升星／洗鍊視窗保留原生 GS，暫不補算括號內的基底 GS，避免開窗時額外同步重繪整份裝備清單。分類與自動精煉／升星照常提供；已在「全部」分類時不再重按原生全部按鈕。重複更新只在狀態改變時寫入 DOM。

### 保持所在頻道

「選項 → 遊戲」的「保持離線遊玩」下方新增「保持所在頻道」，預設關閉。開啟後會自動選擇上次的伺服器，略過開頭的伺服器選擇；打完關卡回主城或重新上線會自動切回上次所在頻道；各大廳分別記憶。上次伺服器已滿或無法使用時，保留手動選擇。頻道已滿時沿用遊戲提示，不反覆重試；開啟保持離線遊玩時優先保持離線。

### 交易搜尋

交易視窗的裝備／卡片／礦石分類下方提供名稱搜尋欄，支援部分名稱與空白分隔關鍵字。切換分類及加入物品後保留搜尋條件，清空即可恢復全部清單；重新開啟交易會清空搜尋。搜尋只篩選待加入的清單，雙方已放入交易的內容完整保留。

### 2.2.16 小地圖座標顯示修正

小地圖標題優先完整顯示座標；寬度不足時，僅將地圖名稱截短並顯示省略號。
